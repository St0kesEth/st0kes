# St0kes engine

A Monte Carlo option engine that runs inside a view call and returns the
standard error of its own estimate with the price.

CA: 0x1390d4e06126082ce98a9fc7ac9cea38507f3ee6

- `src/Engine.sol`: the walk (a variance that feeds on itself, GARCH(1,1);
  Brownian when alpha and beta are zero), four payoffs (call, put,
  average-price call and put), and the error bar. Stateless, pure.
- `src/Live.sol`: the engine bound to tokenised-equity feeds. Spot is the
  feed's latest answer; the variance the walk starts from is read from the
  feed's own publishing rhythm; the coefficients are per-ticker constants.
- `src/Feeds.sol`: generated by `tools/feeds.py` from `data/garch-fits.json`.

Every number in the paper (`web/index.html`, published at
st0kes.blog/engine) is written by the run that checks it:

    forge test                             # unit + audit; writes web/research.js
    forge test --match-path 'test/Live.fork.t.sol'   # against the chain at a fixed block; writes web/fork.js
    python3 tools/cadence.py         # volatility-from-rhythm against realized; writes web/cadence.js
    python3 tools/budget.py          # the public node's view-call budget; writes web/budget.js

The fork test and `tools/budget.py` need the public RPC. `data/` holds the
cached rounds and five-minute bars the volatility check runs on; their
SHA-256 is stamped into `web/cadence.js`.

This is research code, and every number is generated by the run that checks it.

MIT.




## A strike strip from one set of paths

`StripEngine` prices calls and puts at up to 32 strikes, each with its Monte
Carlo standard error, from one set of paths, because the expensive part of a
quote is walking the paths and every strike can reuse them. In paired mode the
128 paths are walked as 64 mirrored pairs that share one variance walk, and the
error is computed across the pairs, since a pair is one independent draw.
`StripLive` binds the strip to one feed snapshot and returns the block, the
seed and the feed timestamp with it.

In the reference benchmark (128 paths, 78 steps, 32 strikes) the 64 paired
prices cost 29,205,723 gas; one scalar at-the-money call costs 35,000,744 and
64 scalar prices would cost 2,239,823,292. The study behind it keeps all 13
profiles, 256 seeds, 3 strikes and both sides, including the four cases where
pairing did not lower the variance (`web/strip-study-*.json`).

`StripEngine` inherits `EngineV2`, which is the deployed engine's walk with a
square root that is exact from any starting guess. The deployed `Engine` is
left exactly as it is on the chain, and `tools/replay.py` and `web/fork.js`
reproduce it to the wei.

```sh
forge test --match-contract 'Strip(EngineTest|Benchmark|Study|LiveTest|ReplayTest)' --fuzz-runs 256 -vv
python3 tools/analyze_strip.py
python3 tools/replay_strip.py
forge test --match-contract StripLiveForkTest -vv
```

The nine at-the-money one-session average-price calls from the paper, live from
the chain (NVDA is index 4):

    cast call 0xEC637733bE276dB2ab3D82Fc1830b2128B430e13 \
      "quote(uint256,uint8,uint256,uint16,uint16,uint16,uint256,uint256)((uint256,uint256,uint256,uint256,uint256,uint256))" \
      4 2 0 78 3 128 64 0 \
      --rpc-url https://rpc.mainnet.chain.robinhood.com

The last argument is the seed. Pass 0 to use the current block number, so the
same call returns a fresh draw at every block and moves inside the error the
quote reports.
